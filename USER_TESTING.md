# User Acceptance Testing (UAT) Insights

1. **Bug: Invisible 3D Models in VR Mode**
   - Users reported that they cannot see the 3D models/artifacts while in VR mode.

2. **Issue: Darkness in VR**
   - The VR environment is too dark, making it difficult to appreciate architectural details or navigate comfortably.

3. **Issue: Performance Degradation**
   - The application suffers from low framerates and performance stuttering, particularly when viewing UI panels or when multiple elements are active.
